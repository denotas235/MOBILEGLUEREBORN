---

### 🔷 MaliWorldMod.java
```
Função:
  Entrypoint do mod. Inicializa todos os sistemas
  na ordem correta. Registra eventos, features,
  estruturas e configurações.

Efeito no jogo:
  Ativa o mod quando o jogo inicia.
  Sem ele nada funciona.
```

```java
public class MaliWorldMod implements ModInitializer {

    public static final String MOD_ID = "maliworld";
    public static final Logger LOGGER =
        LoggerFactory.getLogger(MOD_ID);

    @Override
    public void onInitialize() {
        LOGGER.info("MaliWorld iniciando...");

        // Ordem importa
        MaliWorldConfig.load();
        NoiseRegistry.init();
        FeatureRegistry.register();
        StructureRegistry.register();
        LootTableInjector.inject();
        OptimizationSystems.init();

        LOGGER.info("MaliWorld pronto.");
    }
}
```

## 🌍 MÓDULO WORLDGEN

---

### 🔷 SimplexNoise.java
```
Função:
  Implementação pura em Java do Simplex Noise.
  Não usa bibliotecas externas.
  Base matemática para todo o terreno.

Por que Simplex e não Perlin:
  Simplex tem menos artefatos diagonais
  Mais rápido em dimensões altas
  Resultado mais orgânico
```

---

### 🔷 FractalNoise.java
```
Função:
  Empilha múltiplas camadas de SimplexNoise
  com frequências e amplitudes diferentes.
  Cria o padrão "fractal" do terreno natural.

Efeito no jogo:
  Camada 1 (baixa freq):   continentes e mares
  Camada 2 (média freq):   colinas e vales
  Camada 3 (alta freq):    pedras e relevos
  Camada 4 (muito alta):   micro-detalhes
  Combinadas = terreno que parece geologia real
```

---

### 🔷 DomainWarp.java
```
Função:
  Distorce as coordenadas de entrada do noise
  ANTES de calcular a altura.
  Técnica criada por Inigo Quilez.

Efeito no jogo:
  Sem DomainWarp: terreno matemático perfeito,
                  padrões repetitivos visíveis

  Com DomainWarp: terreno parece "dobrado"
                  nenhuma área parece igual
                  montanhas com formas únicas
                  encostas que viram bruscamente
                  vales profundos inesperados
```

---

### 🔷 TerrainShaper.java
```
Função:
  Combina todos os noises em uma altura final.
  Define quanto cada tipo de terreno domina
  em cada região do mundo.
  Usa "terrain splines" para controle preciso.

Efeito no jogo:
  Planícies permanecem planas
  Transição suave planície → colina → montanha
  Picos montanhosos dramáticos acima de Y=200
  Oceanos com profundidade variada
  Plataformas continentais rasas na costa
```

---

### 🔷 ContinentGenerator.java
```
Função:
  Gera a forma macro do mundo em escala continental.
  Define onde haverá terra vs oceano.
  Cria a "identidade geográfica" de cada região.

Efeito no jogo:
  Ao invés de terra aleatória em todo lugar:
  - Grandes massas continentais separadas por oceanos
  - Ilhas menores espalhadas
  - Arquipélagos em certas regiões
  - Oceanos com bacias profundas
  - Costas com praias e penhascos
```

---

### 🔷 MountainBuilder.java
```
Função:
  Gera cadeias de montanhas coerentes,
  não montanhas aleatórias espalhadas.
  Simula compressão tectônica em linha.

Efeito no jogo:
  Cadeias montanhosas que seguem uma direção
  Picos nevados acima de Y=180
  Vales glaciais entre os picos
  Rochas expostas nas encostas íngremes
  Neve que aumenta gradualmente com altitude
  Cavernas de pedregulho nas bases
```

---

### 🔷 BiomeBlender.java
```
Função:
  Suaviza a transição entre biomas diferentes.
  Usa interpolação bilinear de propriedades
  como temperatura e umidade.

Efeito no jogo:
  Sem blend: você cruza uma linha e de repente
             grama verde vira areia seca

  Com blend: zona de 20-50 blocos de transição
             blocos mistos (grama + areia)
             árvores ficam mais esparsas
             vegetação muda gradualmente
             cor da folhagem transiciona
             luz ambiente muda suavemente
```

---

### 🔷 ClimateMapper.java
```
Função:
  Define temperatura e umidade por posição.
  Usa latitude (distância do spawn) e altitude
  para calcular clima realista.

Efeito no jogo:
  Equador (perto do 0,0):   quente e úmido → Jungle
  Longe do equador:         frio e seco → Taiga/Tundra
  Altitude alta:            sempre frio → Snow
  Costa do oceano:          temperado → Floresta
  Interior continental:     mais extremo → Desert/Savana
  
  Resultado: biomas que fazem sentido geográfico
             navegar para norte = gradualmente mais frio
```

---

### 🔷 SurfaceDecorator.java
```
Função:
  Define qual bloco fica na superfície de cada bioma
  baseado no contexto: altitude, inclinação, umidade.

Efeito no jogo:
  Encosta íngreme de montanha:   pedra exposta
  Planície úmida:                grama espessa
  Vale de rio:                   areia + cascalho
  Planalto seco:                 terra rachada
  Costa:                         areia + cascalho misturado
  Topo de montanha nevada:       neve + gelo
  Caverna exposta:               pedra nua
```

## 🏞️ MÓDULO FEATURES

---

### 🔷 RiverCarver.java
```
Função:
  Esculpe rios no terreno após a geração básica.
  Usa curvas de meandros com noise de ângulo.
  Conecta nascentes em altitude a oceanos/lagos.

Efeito no jogo:
  Rios que nascem em montanhas
  Fazem curvas sinuosas nos vales
  Ficam mais largos conforme descem
  Leito com cascalho e areia
  Margem com areia natural dos dois lados
  Vegetação mais densa perto do rio
  Conecta ao oceano ou lago
  Nunca termina no ar (sempre tem saída)
```

---

### 🔷 LakeGenerator.java
```
Função:
  Cria lagos naturais em depressões do terreno.
  Tamanho varia por bioma e contexto.
  Conecta a rios quando possível.

Efeito no jogo:
  Lagos em vales entre montanhas
  Lagos de cratera em terreno vulcânico
  Oásis no deserto (lago pequeno)
  Lagos de geleira em biomas frios
  Fundo do lago com areia/cascalho/lama
  Reflexo da luz diferente dos oceanos
```

---

### 🔷 PathGenerator.java
```
Função:
  Cria caminhos orgânicos de terra batida
  conectando estruturas e pontos de interesse.
  Segue o terreno com desvio natural.

Efeito no jogo:
  Caminhos que ligam aldeias entre si
  Caminhos que levam a ruínas
  Passagens naturais em montanhas
  Largura varia (mais estreito em subida)
  Sobe e desce com o terreno
  Evita água (contorna rios)
  Sensação de que alguém já passou por ali
```

---

### 🔷 CaveEnhancer.java
```
Função:
  Mixin nas cavernas vanilla para adicionar
  detalhes e torná-las mais dramáticas.
  Não regenera as cavernas, melhora as existentes.

Efeito no jogo:
  Câmaras grandes ocasionais (não só túneis)
  Estalactites e estalagmites em câmaras
  Rios subterrâneos conectando câmaras
  Abertura natural para superfície ocasional
  Lava em câmaras profundas
  Minérios mais concentrados em veios
  Musgo e fungos nas paredes úmidas
```

---

### 🔷 WaterfallPlacer.java
```
Função:
  Detecta onde rios chegam em beiras de penhascos

Efeito no jogo:
  Cascatas descendo de penhascos

## ⚡ MÓDULO OPTIMIZATION

---

### 🔷 GreedyMesher.java
```
Função:
  Substitui o sistema de meshing de chunks do vanilla.
  Agrupa faces adjacentes do mesmo bloco em um
  único quad maior.

Efeito no jogo:
  Parede de pedra 16×16:
  - Vanilla:  1024 vértices (256 faces × 4)
  - Greedy:   4 vértices (1 quad gigante)

  Chunk típico:
  - Vanilla:  ~50.000 vértices
  - Greedy:   ~3.000-5.000 vértices

  Resultado:
  + FPS sobe 30-50% só com isso
  + Construções grandes não causam lag
  + Chunks carregam mais rápido
  + Menos memória de GPU usada
```

---

### 🔷 AsyncLightEngine.java
```
Função:
  Move o cálculo de propagação de luz para
  um thread separado, fora do game thread.

Efeito no jogo:
  Sem async:
  - Colocar tocha = 10-50ms de freeze
  - Quebrar bloco com luz = stutter

  Com async:
  - Colocar tocha = sem freeze
  - Luz aparece gradualmente (natural)
  - Mineração rápida sem stutter
  - Velas e lanternas sem impacto
```

---

### 🔷 AsyncPathfinder.java
```
Função:
  Move o cálculo de pathfinding (A*) de mobs
  para um pool de 2 threads separadas.
  Cacheia paths por 10 ticks se destino igual.

Efeito no jogo:
  Sem async:
  - 20 aldeões movendo = 3ms de lag/tick
  - 50 mobs = game thread congestionado

  Com async:
  - 100 mobs = ~0.3ms no game thread
  - Mobs se movem igual, sem diferença visual
  - Batalhas grandes sem lag de IA
```

---

### 🔷 ChunkGenOptimizer.java
```
Função:
  Pré-calcula noise dos chunks vizinhos
  enquanto o chunk atual ainda está gerando.
  Pool de 3 threads dedicadas à geração.

Efeito no jogo:
  Sem otimização:
  - Andar rápido = borda do mundo visível
  - Chunks brancos/invisíveis à frente

  Com otimização:
  - Chunks sempre gerados antes de chegar
  - Andar a qualquer velocidade sem borda
  - Elytra: chunks pré-gerados no caminho
  - Geração 2-3× mais rápida por thread
```

---

### 🔷 ElytraPredictor.java
```
Função:
  Prevê posição futura do jogador baseado
  na velocidade e direção do voo com elytra.
  Força pré-carregamento dos chunks no caminho.

Efeito no jogo:
  Velocidade 30 bl/s:
  - Prevê 3 segundos à frente
  - Pré-carrega cone de 7×7 chunks
  
  Resultado:
  - Voar com elytra sem chunks brancos
  - FPS estável em voo de alta velocidade
  - Firework boost sem freeze
  - Possível voar indefinidamente
```

## 🔧 MÓDULO MIXIN

---

### Mixins de Worldgen

```
NoiseChunkGeneratorMixin.java
  Intercepta: populateNoise()
  Injeta:     DomainWarp + FBM terrain
  Fallback:   se erro → vanilla normal

BiomeSourceMixin.java
  Intercepta: getBiome()
  Injeta:     ClimateMapper + BiomeBlender
  Fallback:   bioma vanilla original

SurfaceBuilderMixin.java
  Intercepta: buildSurface()
  Injeta:     SurfaceDecorator contextual
  Fallback:   superfície vanilla
```

---

### Mixins de Feature

```
RiverMixin.java
  Intercepta: geração de rios vanilla
  Injeta:     RiverCarver melhorado
  Remove:     rios retos e sem vida vanilla

LakeMixin.java
  Intercepta: geração de lagos vanilla
  Injeta:     LakeGenerator mais natural
```

---

### Mixins de Structure

```
VillageStructureMixin.java
  Intercepta: generateStructure() de aldeias
  Injeta:     RealisticVillage adapter
  Garante:    nunca cancela, só modifica

StrongholdMixin.java
  Intercepta: posicionamento do stronghold
  Injeta:     integra com terreno novo
```

---

### Mixins de Optimization

```
LightingProviderMixin.java
  Intercepta: checkBlock() e updateLight()
  Injeta:     AsyncLightEngine
  Garante:    sem race condition

MobEntityMixin.java
  Intercepta: tick()
  Injeta:     throttle por distância
  Tabela:
    < 32 blocos → tick normal
    32-64 blocos → tick a cada 2
    > 64 blocos → tick a cada 4

PathAwareEntityMixin.java
  Intercepta: startMovingTo()
  Injeta:     AsyncPathfinder + cache

ChunkStorageMixin.java
  Intercepta: getOrLoadChunk()
  Injeta:     pré-calcula noise vizinhos

BlockBreakMixin.java
  Intercepta: tryBreakBlock()
  Injeta:     distribui rebuilds (máx 2/tick)

ExplosionMixin.java
  Intercepta: collectBlocksAndDamageEntities()
  Injeta:     limita raycasts 1352→256

EntityRendererMixin.java
  Intercepta: shouldRender()
  Injeta:     culling por distância e tipo
